چطور فرم لاگین با طراحی BMW ساختم؟

How I built the BMW-style login form

1404/11/28 · 5 دقیقه مطالعه5 min read
HTMLCSSJavaScript

ایده

The idea

می‌خواستم فرمی بسازم که حس یک داشبورد خودرو لوکس را بدهد: پس‌زمینهٔ تیره، کارت شیشه‌ای، خط طلایی و انیمیشن‌های نرم. همه‌چیز فقط با HTML و CSS است.

I wanted a form that feels like a luxury car dashboard: dark background, a glass card, a gold accent line and smooth animations. It is pure HTML and CSS.

ساختار HTML

The HTML

ساختار ساده است: یک کارت، دو فیلد با برچسب شناور و یک دکمه.

The structure is simple: one card, two fields with floating labels and a button.

<form class="card">
  <h2>Sign in</h2>
  <div class="field">
    <input id="u" type="text" placeholder=" " required>
    <label for="u">Username</label>
  </div>
  <div class="field">
    <input id="p" type="password" placeholder=" " required>
    <label for="p">Password</label>
  </div>
  <button type="submit">Drive in</button>
</form>

استایل BMW

The BMW look

رنگ‌های مشکی، سفید و طلایی را با متغیرهای CSS تعریف می‌کنیم. برچسب شناور با انتخابگر :placeholder-shown کار می‌کند، بدون هیچ JavaScript.

Black, white and gold are defined as CSS variables. The floating label works with the :placeholder-shown selector, with no JavaScript at all.

:root { --gold: #c9a24b; --ink: #0a0a0c; }
body { display: grid; place-items: center; min-height: 100vh; background: radial-gradient(circle at 30% 20%, #1c1c22, var(--ink)); }
.card { width: min(360px, 92vw); padding: 36px 30px; border-radius: 18px;
  background: rgba(255,255,255,.05); backdrop-filter: blur(14px);
  border: 1px solid rgba(255,255,255,.1); border-top: 2px solid var(--gold);
  animation: rise .7s ease both; }
.field { position: relative; margin: 22px 0; }
.field input { width: 100%; padding: 14px 4px 6px; color: #fff; background: none;
  border: 0; border-bottom: 1px solid #555; outline: none; transition: border-color .3s; }
.field input:focus { border-color: var(--gold); }
.field label { position: absolute; left: 4px; top: 14px; color: #888; pointer-events: none; transition: .25s; }
.field input:focus + label,
.field input:not(:placeholder-shown) + label { top: -6px; font-size: 12px; color: var(--gold); }
button { width: 100%; padding: 12px; border: 0; border-radius: 10px; cursor: pointer;
  font-weight: 700; background: var(--gold); color: #111; transition: transform .2s, box-shadow .2s; }
button:hover { transform: translateY(-2px); box-shadow: 0 8px 24px rgba(201,162,75,.35); }
@keyframes rise { from { opacity: 0; transform: translateY(24px); } }

جمع‌بندی

Takeaways

با همین چند خط، یک فرم حرفه‌ای دارید. قدم بعدی اعتبارسنجی فرم و اتصال به بک‌اند است.

With just these lines you get a polished form. The next step is validation and a backend connection.
