Building an advanced calculator with JavaScript

Overview

ماشین حساب ما سه بخش دارد: یک نمایشگر، دکمه‌ها و تاریخچه. محاسبه را کتابخانهٔ Math.js انجام می‌دهد که توابع علمی مثل sin و sqrt را هم می‌شناسد؛ این‌طور لازم نیست خودمان تحلیلگر عبارت بنویسیم.

Our calculator has three parts: a display, buttons and a history. The Math.js library does the evaluation and already knows scientific functions like sin and sqrt, so we do not need to write our own expression parser.

آماده‌سازی

Setup

Math.js را از CDN اضافه کنید و یک نمایشگر و ظرف تاریخچه بگذارید.

Add Math.js from a CDN and create a display and a history container.

<script src="https://cdnjs.cloudflare.com/ajax/libs/mathjs/12.4.0/math.min.js"></script>
<input id="display" readonly value="0">
<div id="keys"></div>
<ul id="history"></ul>

منطق ماشین حساب

The logic

تابع press هر دکمه را مدیریت می‌کند. عبارت داخل try/catch محاسبه می‌شود تا ورودی نامعتبر برنامه را خراب نکند، و هر نتیجه به تاریخچه می‌رود.

The press function handles every key. The expression is evaluated inside try/catch so invalid input never breaks the app, and each result goes into the history.

const display = document.getElementById('display');
const historyEl = document.getElementById('history');
const history = [];
let expr = '';

function render() {
  display.value = expr || '0';
}

function calculate() {
  try {
    const result = math.evaluate(expr);
    const line = `${expr} = ${math.format(result, { precision: 10 })}`;
    history.unshift(line);
    historyEl.innerHTML = history.slice(0, 10).map(h => `<li>${h}</li>`).join('');
    expr = String(math.round(result, 10));
  } catch {
    expr = '';
    display.value = 'Error';
    return;
  }
  render();
}

function press(key) {
  if (key === 'C') expr = '';
  else if (key === '⌫') expr = expr.slice(0, -1);
  else if (key === '=') return calculate();
  else expr += key;
  render();
}

'7 8 9 / 4 5 6 * 1 2 3 - 0 . ( + sin( sqrt( ^ ) ⌫ C ='.split(' ').forEach(k => {
  const b = document.createElement('button');
  b.textContent = k;
  b.onclick = () => press(k);
  document.getElementById('keys').append(b);
});
